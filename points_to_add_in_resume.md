## AI Image Captioning Web Application

- Built an end-to-end AI-based image captioning system using deep learning and computer vision.
- Implemented image preprocessing, CNN feature extraction, and fallback rule-based captioning.
- Integrated BLIP (Vision–Language model) to generate natural language captions from images.
- Optimized performance using singleton model loading and persistent feature caching.
- Developed an interactive Streamlit web app with image upload, thumbnails, metadata, and caption download.
- Deployed the application on Streamlit Cloud with a live public demo.
- Technologies: Python, PyTorch, Transformers, Streamlit, NumPy, Computer Vision.
